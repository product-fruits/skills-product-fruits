# Product Fruits workspace overview

Use the Product Fruits MCP tools to produce a concise, evidence-based workspace overview.

1. List the Product Fruits workspaces available to the signed-in user.
2. If exactly one workspace is available, use it. If several are available and the user did not identify one, ask which workspace to analyze.
3. Fetch the selected workspace overview and available content lists. Prefer summary/list tools before detail or user-level tools.
4. Call analytics tools only for published content with activity and only when analytics are relevant to the request.
5. Summarize:
   - workspace and content inventory;
   - notable adoption or engagement signals supported by returned data;
   - gaps or limitations in the available data;
   - two or three concrete follow-up questions worth investigating.

Do not claim that missing data means zero usage. Product Fruits MCP is read-only; do not promise to create, edit, publish, or delete Product Fruits content.
